# CV Overlay Trainer (Educational)

A tiny Android app that draws labeled bounding boxes on a **static training image**
using `Canvas` + `WindowManager`. Used for learning Android overlay APIs and
computer-vision result visualization.

- ❌ Does NOT read other apps' screens
- ❌ Does NOT hook into any game
- ❌ Does NOT capture screen via MediaProjection
- ✅ Renders boxes on a static image you supply
- ✅ Educational / demo only
